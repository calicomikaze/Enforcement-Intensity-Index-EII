# EIII: External Interdiction Intensity Index

Bayesian Zero-Inflated Negative Binomial estimation of enforcement intensity in strategically corrupted data.

**Sean Rogers** | University of South Carolina | Department of Political Science

## Overview

The EIII measures enforcement intensity across sanctioned states by triangulating ten institutional primary sources across four layers. This approach addresses a core measurement problem: the institutions producing enforcement data have survival incentives to misreport. No single source can be treated as ground truth. The EIII constructs a composite measure from sources that lie in different directions for different institutional reasons, recovering signal that any individual source obscures.

The estimation uses a Bayesian ZINB to separate two processes: enforcement intensity (conditional on engagement) and sanctuary (structural non-enforcement). Standard frequentist estimation struggles on this data because the likelihood surface is distorted by the strategically corrupted DGP. The Bayesian framework regularizes estimation through priors and produces full posterior distributions with honest uncertainty quantification.

## EIII Construction

The dependent variable sums four layers of institutional enforcement data:

| Layer | Source | Coverage |
|-------|--------|----------|
| 1. OFAC Executive Actions | Federal Register, OFAC SDN | 1945–2025 |
| 2. Multilateral Designations | OpenSanctions, IMF MONA | 1945–2025 |
| 3. Agency Enforcement | OFAC civil penalties | 2003–2025 |
| 4. Kinetic Operations | COW MID, UCDP/PRIO, GED | 1945–2025 |

`eiii_score = layer1 + layer2 + layer3 + layer4`

## Model

**Count equation** (what drives enforcement intensity given engagement):

```
log(μ) = β₀ + β₁·resource + β₂·friction + β₃·degradation + β₄·fiscal
         + β₅·trend + β₆·regime + β₇·gdp_pc + β₈·friction×fiscal
```

**Zero-inflation equation** (what predicts structural zeros / sanctuary):

```
logit(ψ) = γ₀ + γ₁·regime + γ₂·friction + γ₃·resource + γ₄·degradation + γ₅·trend
```

## Estimation Design

- **Primary regime measure:** V-Dem Electoral Democracy Index
- **Additional:** V-Dem Free and Fair Elections Index
- **Robustness:** Polity5 (frequentist only)
- **Prior sensitivity:** Four Bayesian specifications (Diffuse, Sequential, Skeptical, Restrictive)
- **DV sensitivity:** Four alternative weighting schemes
- **Frequentist baseline:** MLE ZINB for convergent validation

## Panel

- 942 country-years (43 states, 1945–2025)
- 535 complete cases in estimation sample
- Binding constraints: `resource_density` (372 missing), `gdp_pc_log` (259 missing)
- Missing data driven by closed economies without World Bank coverage (DPRK, DDR, early Vietnam)
