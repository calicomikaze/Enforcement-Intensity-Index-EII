# EII: Enforcement Intensity Index

Bayesian Zero-Inflated Negative Binomial estimation of enforcement intensity in strategically produced data.

**Sean Rogers** | University of South Carolina | Department of Political Science

## Overview

The EII measures enforcement intensity across sanctioned states by triangulating ten institutional primary sources across four layers. This approach addresses a core measurement problem: the institutions producing enforcement data have survival incentives to misreport. No single source can be treated as ground truth. The EII constructs a composite measure from sources that lie in different directions for different institutional reasons, recovering signal that any individual source obscures.

The estimation uses a Bayesian ZINB to separate two processes: enforcement intensity (conditional on engagement) and sanctuary (structural non-enforcement). Standard frequentist estimation struggles on this data because the likelihood surface is fragile under extreme overdispersion in strategically produced data. The Bayesian framework regularizes estimation through priors and produces full posterior distributions with honest uncertainty quantification.

## EII Construction

The dependent variable sums four layers of institutional enforcement data:

| Layer | Source | Coverage |
|-------|--------|----------|
| 1. OFAC Executive Actions | Federal Register, OFAC SDN | 1945–2025 |
| 2. Multilateral Designations | OpenSanctions, IMF MONA | 1945–2025 |
| 3. Agency Enforcement | OFAC civil penalties | 2003–2025 |
| 4. Kinetic Operations | COW MID, UCDP/PRIO, GED | 1945–2025 |

`EII_score = layer1 + layer2 + layer3 + layer4`

## Model

**Count equation** (what drives enforcement intensity given engagement):

```
log(μ) = β₀ + β₁·resource + β₂·friction + β₃·degradation + β₄·fiscal
         + β₅·trend + β₆·regime + β₇·gdp_pc + β₈·friction×fiscal
```

**Zero-inflation equation** (what predicts structural zeros / sanctuary):

```
logit(ψ) = γ₀ + γ₁·regime + γ₂·friction + γ₃·resource + γ₄·degradation + γ₅·trend
```

## Estimation Design

- **Primary regime measure:** V-Dem Electoral Democracy Index
- **Additional:** V-Dem Free and Fair Elections Index
- **Robustness:** Polity5 (frequentist only)
- **Prior sensitivity:** Four Bayesian specifications (Diffuse, Sequential, Skeptical, Restrictive)
- **DV sensitivity:** Four alternative weighting schemes
- **Frequentist baseline:** MLE ZINB for convergent validation

## Panel

- 942 country-years (44 states in sample frame, 1945–2025; 32 states in the estimation sample)
- 535 complete cases in estimation sample
- Binding constraints: `resource_density` (372 missing), `gdp_pc_log` (259 missing)
- Missing data driven by closed economies without World Bank coverage (DPRK, DDR, early Vietnam)

## Reproducibility

Exact numerical reproduction requires the original estimation environment (seed 42, single core, PyMC 6.3.1 / ArviZ 1.3.0). On different hardware the same seed yields trivially different MCMC draws (compiler/BLAS differences); an independent-hardware verification run (Sep 2026, identical package versions) reproduced all substantive quantities — identical signs on every decisive coefficient, probability-of-direction values within ±0.005, frequentist estimates to five decimals. The committed result files are the locked run of record.

## Naming Note

The instrument was renamed from the External Interdiction Intensity Index (EIII) to the **Enforcement Intensity Index (EII)** in September 2026. Column names in the panel data (`eiii_score`, `eiii_equal`, `eiii_rawcount`, `eiii_financial`) and the corresponding variable references in the replication script retain the legacy `eiii_` prefix to preserve the integrity of the locked estimation run.
